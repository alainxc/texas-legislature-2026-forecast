# Texas Legislature 2026 Forecast

A FiveThirtyEight-style probabilistic forecast of the November 3, 2026 elections for all 150 Texas House seats and the 16 Texas Senate seats on the ballot, published as a static website. Public data only. Not affiliated with any campaign, caucus, party committee or outlet.

## What is here

| Path | Purpose |
|---|---|
| `config/model_config.yaml` | **Every model weight**, documented inline. Change the model here, nowhere else. |
| `pipeline/fetch/fetch_*.py` | One fetcher per source (TLC district returns and shapefiles, Ballotpedia candidates, SOS legislative results, Texas Ethics Commission finance, polls, ratings, prediction markets). Each writes raw files plus a `manifest.json` with URL and retrieval time into `data/raw/<source>/`. |
| `pipeline/baseline.py` | Layer 1: district partisan lean on current lines. |
| `pipeline/forecast.py` | Layers 2-4, 40,000-run correlated simulation, sensitivity table. Writes `data/processed/forecast_*.{csv,json}`. |
| `pipeline/backtest.py` | Re-runs the model for 2022 and 2024 with pre-election inputs only. |
| `pipeline/build_geo.py`, `pipeline/build_site.py` | Map geometry and the static site (`site/`). |
| `run_all.sh` | One command: fetch, forecast, backtest, build, zip. |
| `make_zip.sh` | Zips `site/` into `site-YYYYMMDD-HHMM.zip` in the repo root. |
| `.github/workflows/deploy.yml` | Deploys to GitHub Pages whichever zip in the repo root was committed most recently. |
| `docs/CHANGELOG.md` | Shown on the site's changelog page. |

Processed files are never hand-edited; every value is regenerated by the pipeline, so refreshing polls cannot wipe anything.

## Run it

Requires Python 3.9+ and internet access. From the repository root:

```bash
./run_all.sh
```

Options: `./run_all.sh --as-of 2026-10-15` runs the model as of a past date (polls after that date are ignored); `./run_all.sh --skip-fetch` reuses the cached raw data. The first run creates `.venv/` and installs `requirements.txt`.

The Texas Ethics Commission fetch downloads a ~1 GB bulk zip into `data/raw/tec/download/` (git-ignored). Everything else is small.

## Publish

1. Create a public GitHub repository and push this folder to its `main` branch.
2. In the repository settings, under Pages, set **Source** to **GitHub Actions**.
3. Every push to `main` deploys the most recently committed `site-*.zip` from the repository root. To update the live site without running anything locally, drag a new zip into the repository root on github.com and commit; to update after a model refresh, run `./run_all.sh` and commit the new zip.

The site is plain HTML, CSS and JavaScript with no build step, so it also works from any static host or by opening `site/index.html` through any local web server.

## Method in one paragraph

District lean from 2020-2024 statewide races aggregated to current lines by the Texas Legislative Council, blended with the district's own legislative results; a candidate layer (incumbency, open seats, finance from TEC cover sheets with a noise floor, prior performance, special-election carryover, explicit third-party modelling); a statewide environment built from weighted public polls (governor, U.S. Senate, Texas generic questions, national generic ballot adjusted for Texas's lean, Abbott approval) plus a structural midterm prior and a documented Texas polling-bias correction; capped nudges from State Navigate ratings and party target lists; then 40,000 simulations with statewide (fat-tailed), regional, Hispanic-share and district error. Full details on the site's methodology page.
