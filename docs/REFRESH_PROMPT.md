# Paste-able prompt to refresh the forecast

Replace the date, open this repository folder in Claude Code, and paste:

> Refresh the Texas Legislature 2026 Forecast in this repository as of YYYY-MM-DD. Read README.md and config/model_config.yaml first. Run `./run_all.sh --as-of YYYY-MM-DD`; if any fetch script fails because a source moved or is bot-blocked, find a public alternative, record its URL and retrieval date in that source's manifest.json, and never type numbers in by hand or edit anything under data/processed. Check the new candidate list, special elections and vacancies against Ballotpedia and the Texas Legislative Reference Library, and re-verify that no legislative map change has happened. Do not change any model weight unless the backtest shows a clear reason; if you do, explain it in one line in docs/CHANGELOG.md. Add a dated entry to docs/CHANGELOG.md describing what changed in the data and how the headline numbers moved. Rebuild the site, make a new zip with ./make_zip.sh, delete the old zip, and commit. Then report: chamber-control odds and expected seats for both chambers with the change since the last run, the ten closest races, the biggest disagreements with State Navigate, the sensitivity table, and anything that could not be verified. Keep the site anonymous: no personal names or employers anywhere.
